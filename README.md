# Dota2 — своя мини-MOBA на C++

Учебный проект: маленькая MOBA («своя дота») и **лёгкий игровой движок** в духе
Source, написанные на C++. Три варианта — от простого 2D-прототипа до движковой
версии с Entity-системой, фикс-тиком и консолью.

## Что внутри

| Папка | Что это | Стек | Как выглядит |
|------|---------|------|--------------|
| [`engine-game/`](engine-game) | **Свой движок** (Entity/World/ticks/cvars/консоль) + дота как «мод» поверх него | C++ / raylib | ![](docs/preview_engine.png) |
| [`mini-moba-3d/`](mini-moba-3d) | 3D-версия игры | C++ / raylib | ![](docs/preview3d.png) |
| [`mini-moba/`](mini-moba) | Первый 2D-прототип | C++ / SFML | ![](docs/preview2d.png) |

Во всех трёх есть общий геймплей: герой с управлением (движение правым кликом,
авто-атака), способности `Q`/`W` с кулдаунами, волны крипов на линии, башни и
трон (Ancient) у каждой стороны, условие победы, вражеский герой-бот, золото и
прокачка уровней.

**Рекомендую смотреть `engine-game/`** — там самое интересное: собственный движок,
через который выражена вся игра, консоль по `~` и cvars (`sv_wave_interval`,
`sv_damage_scale`, `restart`, `win dire`, …).

## Быстрый старт (движковая версия)

Нужны CMake ≥ 3.16 и компилятор C++17. raylib подтянется автоматически.

```bash
cd engine-game
cmake -S . -B build
cmake --build build -j
./build/mini_moba_engine
```

Зависимости на Linux, если raylib собирается из исходников:

```bash
sudo apt-get install -y build-essential cmake \
  libgl1-mesa-dev libx11-dev libxrandr-dev libxinerama-dev \
  libxcursor-dev libxi-dev libglu1-mesa-dev
```

Подробности по каждой версии — в README внутри соответствующей папки.

## Управление

| Действие | Клавиша / мышь |
| --- | --- |
| Двигаться | Правая кнопка мыши |
| Способность Q (болт) / W (щит) | `Q` / `W` |
| Зум камеры (3D/движок) | Колесо мыши |
| Консоль (движок) | `~` |
| Рестарт после матча | `R` |
| Выход | `Esc` |
